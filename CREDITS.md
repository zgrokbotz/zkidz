Files live in `audio/` as mono, 22.05 kHz OGG Vorbis (compressed from the original downloads).

The single-file `zkidz-standalone.html` does **not** embed these tracks, so the file stays smaller. When you open it from the game folder (or the live site), it loads `audio/*.ogg` next to the page. If you open the HTML file by itself, it falls back to the hosted copies at https://zgrokbotz.github.io/zkidz/audio/.
